# Data Storage Conventions

This directory houses datasets across different lifecycle stages. All data files (except `.gitkeep` and documentation) are ignored by git to avoid committing large binary files.

## Subdirectories

- **`raw/`**: Unmodified, immutable source data (e.g., downloaded zip/tar files, raw CSVs/JSONs). Never edit files in this folder manually.
- **`interim/`**: Intermediate processed datasets, such as mapped integer user/item continuous IDs, deduplicated records, and parsed timestamps.
- **`processed/`**: Ready-to-train datasets, dense interaction tensors, sparse CSR/COO matrices, and pre-computed item/user embeddings.
- **`splits/`**: Deterministic train, validation, and test splits (e.g. `train.parquet`, `val.parquet`, `test.parquet`) generated by `src/splits/`.

## Data Versioning

For tracking large datasets in team environments, consider using [DVC (Data Version Control)](https://dvc.org) or S3/GCS bucket syncing:

```bash
# Example DVC tracking
dvc add data/raw/movielens-1m
dvc push
```
